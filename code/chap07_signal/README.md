# Chapter 7: signal processing with reproducible synthetic CSV inputs

All 31 original block IDs retain their first-edition hashes. The author approved
synthetic replacement of the three lost CSV inputs on 2026-11-09. Historical
filenames are kept; **the new data are not measured solar activity, a telephone
recording or real GOOG quotations**. `input-sources.json` records the generator,
seed, dimensions, parameters and hashes. No external download is needed.

Run `python3 generate_inputs.py --check` in this directory to verify exact
reproducibility. Running without `--check` regenerates the checked-in CSV files:

- `sunspot_full.csv`: 321 annual samples, 1700–2020 labels, a known 11-year
  periodic component with amplitude modulation and small noise.
- `touchtone.csv`: 8192 Hz, sequence `12345678901`, 5000 samples per key and
  1000 silent samples per gap, with standard paired DTMF frequencies.
- `goog.csv`: 251 synthetic OHLCV-like observations with sample indices,
  a slow trend, periodic components and noise; no actual trading dates/prices.

Run `python3 scripts/run_chapter07.py` from the repository root in the book image.
All 31 canonical regions execute; 104 numerical/property checks include actual
CSV parsing, injected-period recovery, all eleven digits decoded from FFT peaks,
OHLC consistency, smoothing, DC preservation and odd-length reconstruction.
Fourteen book figures are rendered and decoded. Full records are generated by
the runner; manuscript exporters keep them outside the publication snapshots.

The original noisy-cat input and double-precision image FFT path are retained.
`book_signal.ml` supplies true FFT bin/period axes, normalized Gaussian kernels,
VALID moving averages and an odd-length-safe real inverse transform. The existing
single-precision native roundtrip test does not assert that the known problematic
complex32 bytecode binding works.
