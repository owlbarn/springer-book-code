# Regent Street input and rendered book figure

“Regent Street, London (June 2009)” by Mark Pegrum (Flickr account OzMark17).
Source: https://www.flickr.com/photos/ozmark17/3864732604/
License: Creative Commons Attribution 2.0, https://creativecommons.org/licenses/by/2.0/
The original JPEG and exact hash are recorded in `data/london-photo.json`.
The chapter crops the bottom 2048 × 916 pixels from the 2048 × 1536 version,
then applies current Mask R-CNN masks, boxes and labels. The derivative retains
this attribution and identifies those changes. The first-edition figure used
this same framing; a geometric match is preserved in the review evidence.
The photo publisher's oEmbed and page metadata independently declare CC BY 2.0.

The original upstream sheep/Toronto examples were used only as temporary local
probes. They are not substituted for the book's London image or shipped here.
