# Chapter 1: executable introductory examples

Run `python3 scripts/run_chapter01.py --output /tmp/chapter01` in the book image.
The normal CDF spelling and Black–Scholes denominator now agree with the printed
formula: divide by `sigma * sqrt t`. The original code multiplied by `sqrt t`,
which a one-year fixture alone cannot expose. A quarter-year fixture, expiry,
zero volatility, bounds and monotonicity are checked. The original small convolution network is
initialised and actually run; its output shape and probability normalisation are
checked. Both source excerpts also run in a real OCaml interpreter.
